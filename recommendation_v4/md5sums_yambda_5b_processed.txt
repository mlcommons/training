# MD5 checksums for the preprocessed yambda-5b dataset (processed_5b/).
#
# Format: standard `md5sum` output -> "<md5hash>  <relative_path>".
# Paths are relative to ${DLRM_DATA_PATH}/processed_5b/.
#
# Verify with:
#
#   DLRM_DATA_PATH=/path/to/dlrm_data ./verify_dataset.sh
#
# or directly:
#
#   cd "${DLRM_DATA_PATH}/processed_5b"
#   md5sum -c <repo>/md5sums_yambda_5b_processed.txt
#
# These pin the canonical preprocessing output: 47,618,139,057 bytes across the
# five files below, produced by scripts/crusoe_spur/preprocess_5b.sbatch from
# the yandex/yambda HuggingFace snapshot
# dd6f3a19eef5866e346c3270e098baa641a44948. Regenerate with
# scripts/crusoe_spur/md5_processed_5b.sbatch.
#
# Not covered here: hstu_cache_L4086/ is a derived mmap cache the dataset
# rebuilds on demand, and shared_metadata/ holds unmodified upstream artifacts.
#
# Note that these hash the byte-for-byte artifacts, so they verify a copy or a
# download of this dataset. Re-running preprocessing on another machine can
# produce logically identical parquet files with different bytes, since the
# parquet writer records its own version and row-group layout.
